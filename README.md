# Snake Game (Python)

This is a classic Snake game developed using Python. The game is designed with a modular structure, where different parts of the game are separated into individual files for better organization and readability. The player controls a snake that moves around the screen, eats food to grow longer, and scores points while avoiding collisions with the walls or its own body.

The project includes separate modules for the main game loop, snake behavior, food generation, and the scoreboard system.

## Features
- Classic Snake gameplay
- Modular code structure
- Snake growth when food is eaten
- Score tracking using a scoreboard
- Simple and responsive keyboard controls

## Technologies Used
- Python 3
- Turtle (Python built-in library)

## Project Structure
```
main.txt        # Main game loop and screen setup
snake.txt      # Snake movement and growth logic
food.txt       # Food creation and positioning
scoreboard.txt # Score display and tracking
README.md
```

## How to Run
Make sure Python 3 is installed on your system. Keep all the `.txt` files in the same directory. If necessary, rename `main.txt` to `main.py`, then run the game using the following command:

```
python main.py
```

## Controls
- Up Arrow: Move Up  
- Down Arrow: Move Down  
- Left Arrow: Move Left  
- Right Arrow: Move Right
